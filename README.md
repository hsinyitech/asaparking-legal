# asaparking-legal

ASAParking iOS App 的法律文件 hosting，透過 GitHub Pages 服務。

## 內容

- [`privacy-policy.md`](privacy-policy.md) — 隱私權政策（zh-TW）
- [`terms-of-service.md`](terms-of-service.md) — 服務條款（zh-TW）
- [`index.md`](index.md) — 落地頁

## 發佈

GitHub Pages 啟用方式：repo Settings → Pages → Source = `Deploy from a branch` → Branch = `master` → Folder = `/ (root)`。

啟用後 URL：

- https://hsinyitech.github.io/asaparking-legal/
- https://hsinyitech.github.io/asaparking-legal/privacy-policy
- https://hsinyitech.github.io/asaparking-legal/terms-of-service

## 同步來源

主 markdown 來源在 ASAParking repo 的 `docs/legal/`。修改後 `cp` 過來重新 commit 即可。
